## 何を app 化したか

- 原典の `(i)` から `(iii)` を app 内の内部タブへ分けた。
- `(i)` では $T=Z/\sqrt{V/m}$ をそのまま乱数で構成し、[[標準正規分布]] と [[カイ2乗分布]] がどう結合されるかを見える形にした。
- `(ii)` では t 分布の pdf を直接描き、自由度によって裾の重さがどう変わるか、そして自由度が増えると [[標準正規分布]] へ近づくことを可視化した。
- `(iii)` では
  $T=(\bar{X}-\mu)/(s/\sqrt{n})$
  を正規乱数標本から計算し、標本平均の t 統計量が $t(n-1)$ に従うことをヒストグラムと観測内訳表で示した。

## データの素性

- 1.7 は理論中心の節であり、原典に固定の観測データ表はない。
- そこで app では、標準正規乱数、カイ2乗乱数、正規母集団からの標本を補助生成し、t 分布の構成を手で追えるようにした。
- DGP は「原典データの再掲」ではなく、「原典の数式を理解するための補助実験」である。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $T\sim t(m)$ | 自由度 $m$ の t 分布 | `student_t_pdf(x_grid, m)` |
| $Z$ | 標準正規成分 | `z_values` |
| $V$ | カイ2乗成分 | `v_values` |
| $T=Z/\sqrt{V/m}$ | 定義に基づく t 統計量 | `t_values` |
| $(\bar{X}-\mu)/(s/\sqrt{n})$ | 標本平均の t 統計量 | `t_values` |

## 主要関数の意味

### 1. t 分布の構成

```python
def simulate_t_definition(degrees_of_freedom, n_simulations, seed):
    z_values = rng.normal(0.0, 1.0, size=n_simulations)
    v_values = rng.chisquare(degrees_of_freedom, size=n_simulations)
    t_values = z_values / np.sqrt(v_values / degrees_of_freedom)
```

- 原典の `(i)` の定義をそのままコード化している。
- t 分布乱数を直接呼ばず、Z と V の 2 つの部品を先に作ってから比を作る構成にした。

### 2. t 分布の pdf

```python
student_t_pdf(x_values, degrees_of_freedom)
```

- 原典の式 (1.51) を Gamma 関数つきで直接実装している。
- 自由度で裾がどう変わるかを、標準正規と重ねて読めるようにしている。

### 3. 標本平均の t 統計量

```python
t_values = (sample_means - true_mu) / (np.sqrt(s2_values) / math.sqrt(n_samples))
```

- 原典の式 (1.52) に対応する。
- 正規母集団からの標本平均と不偏分散を同時に計算し、t(n-1) と照合している。

## なぜこの構成にしたか

- 1.7 は t 分布の式だけを覚える節ではなく、Z と V の独立性から t 統計量が出る論理を押さえる節だから。
- そこで app では、定義、pdf、標本平均という 3 段を明確に分け、まず部品、次に分布形、最後に具体的な統計量へ進む構成にした。
