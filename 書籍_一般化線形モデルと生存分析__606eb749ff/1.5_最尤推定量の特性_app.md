## 何を app 化したか

- 原典が挙げる 3 性質、すなわち不変性、不偏でない場合があること、すぐれた漸近的特性をもつこと。
- 不変性については Poisson 分布の母数 λ と、その変換 g(λ) を補助例にして、g(λ_hat) が変換後の MLE になることを可視化した。
- 不偏でない例については Normal 分布の分散 MLE を使い、
  $E(\hat{\sigma}^2)=\left(\frac{n-1}{n}\right)\sigma^2$
  をシミュレーションで確認できるようにした。
- 漸近的な良さについては、同じ分散 MLE を使って bias が $n$ とともに 0 へ近づく様子を数表とグラフで見せた。

## データの素性

- 1.5 は一般理論の整理なので、原典本文には固定データ表はない。
- そこでこの app では、Poisson と Normal の乱数標本を補助生成し、各性質の意味を手で追えるようにしている。
- したがって DGP は「原典データの再現」ではなく、「原典の性質を理解するための足場」である。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $\hat{\theta}$ | 母数 $\theta$ の MLE | `mle_lambda`, `mle_variances` |
| $g(\theta)$ | 母数の変換 | `transform_name` |
| $g(\hat{\theta})$ | 変換後の MLE | `transformed_mle` |
| $E(\hat{\theta})$ | 推定量の平均 | `np.mean(mle_variances)` |
| $\operatorname{bias}(\hat{\theta})$ | 平均と真値との差 | `np.mean(mle_values) - true_variance` |
| $\hat{\theta}\sim_{asy}N(\theta, I(\theta)^{-1})$ | MLE の漸近正規性 | 1.4 との理論接続として説明 |

## 主要関数の意味

### 1. Poisson 尤度と不変性

```python
def poisson_loglikelihood(candidate_lambda, sample_sum, n_samples):
    return sample_sum * math.log(candidate_lambda) - n_samples * candidate_lambda

def inverse_transform(transform_name, transformed_value):
    ...
```

- Poisson の対数尤度を直接書き、変換後の候補値を逆変換で λ に戻して同じ尤度へ流す。
- これによって、元の母数で最大になる点と、変換後の母数で最大になる点が対応することを見せている。

### 2. Normal 分散 MLE と不偏分散

```python
centered = samples - sample_mean[:, None]
mle_variance = np.mean(centered ** 2, axis=1)
unbiased_variance = np.sum(centered ** 2, axis=1) / (n_samples - 1)
```

- 同じ標本から MLE の $\hat{\sigma}^2$ と不偏分散 $s^2$ を同時に計算する。
- 平均を比較することで、MLE は有限標本では真値を少し下回ることがある、という原典の主張を確認できる。

### 3. 漸近的不偏性の確認

```python
for n_samples in n_values:
    _, _, mle_values, _ = simulate_normal_variance_estimators(...)
    empirical_bias = np.mean(mle_values) - true_variance
```

- 標本サイズ $n$ を段階的に増やし、経験的 bias が 0 に近づくかを表にまとめている。
- これが原典でいう「漸近的不偏性」の補助確認になる。

## なぜこの構成にしたか

- 1.5 は文章量が短く、要点だけ並べると「何が嬉しくて、何に注意すべきか」が伝わりにくいから。
- そこで app では、各性質を 1 つの補助例に落とし込み、上段を観測や計算の内訳表、下段を分布や要約表に分けた。
- とくに不偏性と漸近的不偏性を混同しやすいので、有限標本の平均の話と、大標本で bias が消える話を別段で見せる構成にした。
