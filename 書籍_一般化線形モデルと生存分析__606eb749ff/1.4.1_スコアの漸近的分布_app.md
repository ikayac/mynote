## 何を app 化したか

- 原典の式 (1.19) から (1.24) にある、スカラーのスコアの平均 0 と分散 = 情報量の関係。
- 原典の式 (1.25) から (1.30) にある、ベクトルのスコアの平均 0 と共分散 = 情報行列の関係。
- 具体例として、Bernoulli 分布のスカラー・スコアと、Normal 分布の 2 変数スコアを補助シミュレーションで可視化した。

## データの素性

- 1.4.1 の本文は一般理論であり、紙面には固定の生データ列はない。
- したがってこの app は、原典の一般式を目で追えるようにするための補助例として、Bernoulli と Normal の乱数標本を生成している。
- DGP は「原典の再現データ」ではなく、「原典の理論を読むための足場」である。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $S(\theta; x)$ | 標本スコア | `bernoulli_dataset_score`, `normal_dataset_score` |
| $I(\theta)$ | フィッシャー情報量または情報行列 | `bernoulli_information`, `normal_information_matrix` |
| $\dfrac{\partial \log L}{\partial \theta}$ | スカラーのスコア | `bernoulli_score_components` |
| $\dfrac{\partial \log L(\theta)}{\partial \theta}$ | ベクトルのスコア | `normal_score_components` |
| $\operatorname{var}(S)$ | スカラーの分散 | `np.var(scalar_scores, ddof=0)` |
| $\operatorname{cov}(S)$ | ベクトルの共分散 | `np.cov(np.column_stack([score_mu, score_variance]).T, ddof=0)` |

## 主要関数の意味

### 1. Bernoulli のスカラー・スコア

```python
def bernoulli_score_components(sample, probability):
    return sample / probability - (1.0 - sample) / (1.0 - probability)

def bernoulli_dataset_score(sample, probability):
    return float(np.sum(bernoulli_score_components(sample, probability)))
```

- 原典の

$$
S(\theta; x)=\frac{\partial \log L}{\partial \theta}
$$

  を、Bernoulli の成功確率 $p$ に対して具体化したもの。
- 各観測の寄与を分けて計算し、その総和を標本スコアとしている。

### 2. Normal のベクトル・スコア

```python
def normal_score_components(sample, mu, variance):
    first_component = (sample - mu) / variance
    second_component = -0.5 / variance + ((sample - mu) ** 2) / (2.0 * (variance ** 2))
    return first_component, second_component
```

- パラメータを $\theta=(\mu,\sigma^2)$ としたときの 2 成分スコアをそのまま実装している。
- app では散布図で点群の中心が原点付近に来る様子を見せ、平均 0 を視覚化している。

### 3. 情報量の理論値

```python
def bernoulli_information(n_samples, probability):
    return n_samples / (probability * (1.0 - probability))

def normal_information_matrix(n_samples, variance):
    return np.array([[n_samples / variance, 0.0], [0.0, n_samples / (2.0 * (variance ** 2))]])
```

- スカラーでは理論分散の比較対象として $I(\theta)$ を返す。
- ベクトルでは共分散行列の比較対象として情報行列を返す。

## なぜこの構成にしたか

- 1.4.1 は具体的な最尤推定値を求める章ではなく、スコアそのものの確率的性質を述べる章だから。
- そのため app では「最適化」よりも、「平均 0」と「分散または共分散 = 情報量」を最優先で見せている。
- 一般理論だけだと抽象度が高いため、補助例として Bernoulli と Normal を置いた。
