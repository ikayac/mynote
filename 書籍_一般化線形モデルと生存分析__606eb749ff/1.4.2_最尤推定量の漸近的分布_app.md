## 何を app 化したか

- 原典の式 (1.31) から (1.40) にある、スコアベクトル $S(\theta)$ の定義。
- $S(\hat{\theta})=0$ を真の母数 $\theta$ のまわりでテイラー展開し、残余項 $R$ を無視できる形へ持ち込む流れ。
- $\dfrac{1}{\sqrt{n}}S(\theta)$ が中心極限定理で正規分布へ近づき、$\dfrac{1}{n}[\Delta S(\theta)]^{\prime}$ が $-M(\theta)$ へ確率収束することで、$\sqrt{n}(\hat{\theta}-\theta)$ が正規分布へ近づくこと。
- 具体例として、Bernoulli の $\hat{p}$ と Normal の $(\hat{\mu},\hat{\sigma}^2)$ を補助シミュレーションで可視化した。

## データの素性

- 1.4.2 は一般理論なので、原典そのものには固定の観測列は載っていない。
- そこでこの app では、Bernoulli と Normal の乱数標本を補助生成し、導出の意味を目で追えるようにしている。
- したがって DGP は「原典データの再現」ではなく、「原典の一般理論を理解するための足場」である。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $Z(x_i;\theta)$ | 1 観測ごとのスコア寄与 | `bernoulli_score_terms`, `normal_score_components` |
| $S(\theta)$ | 全標本のスコア | `score_values`, `score_matrix` |
| $[\Delta S(\theta)]^{\prime}$ | スコアのヤコビアンまたはヘッセ行列の総和 | `hessian_values`, `hessian_stack` |
| $M(\theta)$ | 1 観測あたりの情報量 | `bernoulli_information_per_observation`, `normal_information_per_observation` |
| $\sqrt{n}(\hat{\theta}-\theta)$ | 正規化した最尤推定誤差 | `scaled_errors`, `scaled_matrix` |

## 主要関数の意味

### 1. Bernoulli のスカラー例

```python
def simulate_bernoulli_mle(probability, n_samples, n_simulations, seed):
    samples = rng.binomial(1, probability, size=(n_simulations, n_samples)).astype(float)
    mle_values = np.mean(samples, axis=1)
    score_values = np.sum(bernoulli_score_terms(samples, probability), axis=1)
    hessian_values = np.sum(bernoulli_hessian_terms(samples, probability), axis=1)
    scaled_errors = np.sqrt(n_samples) * (mle_values - probability)
```

- $\hat{p}=\bar{X}$ を何度も計算し、$\sqrt{n}(\hat{p}-p)$ の分布を描く。
- 同時に、スコア $S(p)$ と 2 階微分の和も計算し、原典の式 (1.37) に対応づけている。

### 2. Normal のベクトル例

```python
def simulate_normal_mle(mu, variance, n_samples, n_simulations, seed):
    samples = rng.normal(mu, math.sqrt(variance), size=(n_simulations, n_samples))
    mle_mu = np.mean(samples, axis=1)
    mle_variance = np.mean((samples - mle_mu[:, None]) ** 2, axis=1)
    scaled_mu = np.sqrt(n_samples) * (mle_mu - mu)
    scaled_variance = np.sqrt(n_samples) * (mle_variance - variance)
```

- 母数ベクトルを $(\mu,\sigma^2)$ とし、最尤推定量の 2 成分ベクトルを補助的に可視化している。
- 散布図は $\sqrt{n}(\hat{\theta}-\theta)$ の標本近似分布そのものを表している。

### 3. 情報量 M(theta) と漸近分散

```python
def bernoulli_information_per_observation(probability):
    return 1.0 / (probability * (1.0 - probability))

def normal_information_per_observation(variance):
    return np.array([[1.0 / variance, 0.0], [0.0, 1.0 / (2.0 * (variance ** 2))]])
```

- 原典の $M(\theta)$ は 1 観測あたりの情報量である。
- 最終結果

$$
\sqrt{n}(\hat{\theta}-\theta) \xrightarrow{d} N(0, M^{-1}(\theta))
$$

  を、シミュレーションの共分散と理論値の比較として見せている。

## なぜこの構成にしたか

- 1.4.2 の本文は抽象度が高く、$Z_i$, $S(\theta)$, $[\Delta S(\theta)]^{\prime}$, $M(\theta)$ の役割が見えにくいから。
- そこで app では、Bernoulli でスカラーの漸近正規性、Normal でベクトルの漸近正規性を並べ、同じ構造が繰り返されていることを可視化した。
- 上段は 1 観測ごとの寄与表、下段は推定量の分布表に分け、何を検算しているかを混同しないようにした。
