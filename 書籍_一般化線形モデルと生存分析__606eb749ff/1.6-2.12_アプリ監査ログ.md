# 1.6-2.12 アプリ監査ログ

> [!abstract] 概要
> 2026-04-18 に 1.6 節以降の教材 app を最新版ルールで再監査した記録。主眼は「平易説明と 1 歩ずつ導出を同一タブまたは同一セクションへ置く」「overbrace と underbrace を露出する」「headless 起動で HTTP 200 を確認する」の 3 点。

## 変更した app

- [[1.6_カイ2乗分布_app]]: tab2 に平易説明と段階導出を同居させ、式分解の overbrace / underbrace を補強した。
- [[1.7_スチューデントのt分布_app]]: same-tab 導出の残り 1 箇所を tab2 へ戻し、t 統計量の導出を平易説明の近くで追えるようにした。
- [[1.8_F分布_app]]: F 統計量の導出を tab2 に寄せ、比の構造が見える overbrace / underbrace を補った。
- [[1.9.1_尤度比検定_app]]: 尤度比統計量の導出を tab2 に統合し、検定統計量の各部品を式上で分解した。
- [[1.9.2_ウォルド検定_app]]: Wald 統計量の平易説明と導出を tab2 に集約し、標準化されたズレの意味を式上で見える形にした。
- [[1.9.3_スコア検定_app]]: LM 統計量の導出を tab2 に統合し、score と情報量の関係を overbrace / underbrace で補強した。
- [[1.10_検定の棄却域_app]]: LR, W, LM の棄却域説明を same-tab で往復できるようにし、局所対立との接続を追いやすくした。
- [[例1.9_パラメータに関する複合仮説_app]]: 複合仮説下の LR, W, LM の導出を tab2 に寄せ、分割情報行列の役割を式分解で示した。
- [[2.2_回帰モデル_app]]: 回帰式と行列表現のつながりを same-tab で追えるようにし、記号対応を式分解で補強した。
- [[2.11_仮説検定_app]]: t 検定と F 検定の導出を tab2 に集約し、t^2 = F や RSS 差分との対応を同一セクションで追えるようにした。
- [[2.12_p値_app]]: p 値の定義と最小有意水準としての意味を tab2 の中で導出と一緒に見られるようにした。
