## 1. 原典で何をしているか

原典 1.3.2 は、まず一般形として

$$
L(\theta)=\prod_{i=1}^n f(x_i;\theta)
$$

と

$$
\log L(\theta)=\sum_{i=1}^n \log f(x_i;\theta)
$$

を置き、これを微分して $0$ と置くことで最尤推定量を求める、という原則を示しています。

さらに、具体例として次の 3 つが続きます。

1. 二項分布では

$$
\hat{p}=\frac{x}{n}
$$

2. ポアソン分布では

$$
\hat{\lambda}=\bar{x}
$$

3. 正規分布では

$$
\hat{\mu}=\bar{x}, \qquad \hat{\sigma}^2=\frac{1}{n}\sum_{i=1}^n (x_i-\bar{x})^2
$$

が得られます。

---

## 2. アプリで使った補助標本の素性

二項分布の例は原典どおり $n=10, x=6$ をそのまま扱えますが、ポアソン分布と正規分布については、グラフと対数尤度曲線を見せるために**固定の補助標本**を置いています。

```python
POISSON_SAMPLE = np.array([2, 3, 1, 4, 2, 5, 3, 2], dtype=float)
NORMAL_SAMPLE = np.array([48.0, 52.0, 51.0, 47.0, 55.0, 49.0, 53.0, 46.0], dtype=float)
```

これは原典そのものの観測値ではありません。あくまで、

1. 対数尤度の山がどこに立つか
2. 微分方程式から出た MLE がどこへ対応するか
3. 正規分布の 2 変数対数尤度がどんな地形になるか

を可視化するための説明用データです。乱数ではなく固定配列なので、毎回同じ結果が再現されます。

## 3. 原典の数式をどうコードへ落としたか

### 3.1 二項分布

```python
def binomial_likelihood(n_trials, successes, p):
  return math.comb(n_trials, successes) * (p ** successes) * ((1.0 - p) ** (n_trials - successes))

def binomial_loglikelihood(n_trials, successes, p):
  return math.log(math.comb(n_trials, successes)) + successes * math.log(p) + (n_trials - successes) * math.log(1.0 - p)
```

これは

$$
L(p)=\binom{n}{x}p^x(1-p)^{n-x}
$$

と

$$
\log L(p)=\log \binom{n}{x}+x\log p+(n-x)\log(1-p)
$$

をそのままコード化したものです。微分して

$$
\frac{d\log L(p)}{dp}=\frac{x}{p}-\frac{n-x}{1-p}=0
$$

を解けば

$$
\hat{p}=\frac{x}{n}
$$

が得られるので、アプリではその値と曲線の頂上が一致することを確認できるようにしました。

### 3.2 ポアソン分布

```python
def poisson_loglikelihood(data, lam):
  log_factorial_sum = sum(math.lgamma(x + 1.0) for x in data)
  return -len(data) * lam + float(np.sum(data)) * math.log(lam) - log_factorial_sum
```

この関数は

$$
\log L(\lambda)=-n\lambda+\sum_{i=1}^n x_i\log \lambda-\sum_{i=1}^n \log x_i!
$$

をそのまま書いています。$x_i!$ の項は `math.lgamma(x + 1.0)` を使って計算しています。

微分方程式

$$
\frac{d\log L(\lambda)}{d\lambda}=-n+\frac{\sum_{i=1}^n x_i}{\lambda}=0
$$

から

$$
\hat{\lambda}=\bar{x}
$$

が出るので、アプリでは `np.mean(POISSON_SAMPLE)` を MLE として表示しています。

### 3.3 正規分布

```python
def normal_loglikelihood(data, mu, variance):
  residual_sum = float(np.sum((data - mu) ** 2))
  n_samples = len(data)
  return -(n_samples / 2.0) * math.log(2.0 * math.pi) - (n_samples / 2.0) * math.log(variance) - residual_sum / (2.0 * variance)
```

これは

$$
\log L(\mu,\sigma^2)=-\frac{n}{2}\log(2\pi)-\frac{n}{2}\log \sigma^2-\frac{1}{2\sigma^2}\sum_{i=1}^n (x_i-\mu)^2
$$

を計算しています。

さらに、等高線図を描くために

```python
def normal_loglikelihood_grid(data, mu_grid, variance_grid):
  grid = np.zeros((len(variance_grid), len(mu_grid)))
  for i, variance in enumerate(variance_grid):
   for j, mu in enumerate(mu_grid):
    grid[i, j] = normal_loglikelihood(data, float(mu), float(variance))
  return grid
```

で格子点上の値を並べています。これは最適化のためではなく、**原典の偏微分方程式が作る地形を見せるための可視化前処理**です。

## 4. アプリ本体の「全使用コード解説」タブで何を説明しているか

今回の 1.3.2 アプリには、1.3.1 と同じく**全使用コード解説タブ**を入れました。そこで説明している対象は次の通りです。

1. `bernoulli_sample(...)`
  二項分布の観測結果を 0/1 配列として可視化する補助関数。
2. `binomial_likelihood(...)`, `binomial_loglikelihood(...)`
  二項分布の尤度と対数尤度をそのまま評価する関数。
3. `poisson_loglikelihood(...)`
  ポアソン分布の対数尤度を評価する関数。
4. `normal_loglikelihood(...)`
  正規分布の 2 変数対数尤度を返す関数。
5. `normal_loglikelihood_grid(...)`
  等高線図を描くために格子点上の対数尤度を作る関数。
6. `notation_reference_rows(...)`
  原典の記号とコードの変数名の対応を一覧表示する補助関数。

これにより、学習者はアプリ画面の中だけで、原典の式とコードの対応を往復できます。

## 5. ブラックボックス代替候補として何があるか

アプリ本体のコード解説タブには、もしスクラッチ実装をやめて**内部が隠蔽された推論・解析ライブラリ**へ寄せるなら何が候補になるか、という補足も加えています。

代表例は次の通りです。

1. `scipy.stats.binom.pmf`, `scipy.stats.poisson.logpmf`, `scipy.stats.norm.logpdf`
  分布式の評価を関数呼び出しへ隠します。
2. `scipy.optimize.minimize`
  MLE の最大化自体を数値最適化へ隠します。
3. `statsmodels.api.GLM` と各 `family`
  二項・ポアソン・正規の当てはめと結果要約を内部化します。
4. `PyMC`, `CmdStanPy`, `TensorFlow Probability`
  さらに広い確率モデリングやベイズ推定の枠組みへ包み込みます。

このアプリでは、それらを**実装していません**。目的が「MLE の導出を自分の目で追うこと」だからです。補足表は、ブラックボックス化される場所を可視化するために置いています。

## 7. まとめ

1.3.2 は、前節で見た「尤度の山の頂上」を、微分方程式として掴みにいく節です。アプリではその流れを、二項分布・ポアソン分布・正規分布の 3 例で可視化しました。

特に重要なのは、

1. 対数変換を使っても最大点は変わらないこと
2. 微分して $0$ と置くことで MLE が求まること
3. 解析解が出る場合は、グラフの頂上と式の答えが一致すること

を、式・グラフ・コードで同時に追えるようにした点です。
