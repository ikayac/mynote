## 何を app 化したか

- 原典の式 (1.64) の
  $LM=S(\theta_0)'I(\theta_0)^{-1}S(\theta_0)$
  を、二項分布の成功確率 $p$ で実演した。
- 帰無仮説の下での score を観測ごとに分解し、「まだ尤度が上がりそうか」を傾きとして読めるようにした。
- score を情報量で標準化した Z と、その二乗の LM を、帰無仮説の下の反復標本で確認できるようにした。

## データの素性

- 原典に固定の観測データはないため、app では二項分布の標本を補助生成している。
- 目的は、対立仮説側を毎回最適化しなくても、帰無仮説の地点だけで検定が作れることを体感することにある。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $S(\theta_0)$ | 帰無仮説の下での score | `score_value` |
| $I(\theta_0)$ | 帰無仮説の下での情報量 | `information` |
| $LM$ | スコア検定統計量 | `lm_value` |
| $S(\theta_0)/\sqrt{I(\theta_0)}$ | 正規近似で見る score-Z | `score_z` |

## 主要関数の意味

### 1. score の計算

```python
def binomial_score(successes, n_trials, probability):
    return successes / probability - (n_trials - successes) / (1.0 - probability)
```

- 帰無仮説の下での対数尤度の傾きを、そのまま score として計算している。

### 2. LM 統計量

```python
def score_statistic(n_trials, successes, null_probability):
    score = binomial_score(successes, n_trials, null_probability)
    information = binomial_fisher_information(n_trials, null_probability)
```

- 原典のスカラー版で、score の二乗を帰無仮説下の情報量で割っている。

## なぜこの構成にしたか

- 1.9.3 の肝は、「帰無仮説の地点の傾きだけで判定できる」ことにある。
- そこで app では、1 標本に対する score の分解表と、帰無仮説下での Z/LM の漸近分布確認を分けた。

## ブラックボックス化される候補

- `statsmodels` の score test utilities
- `scipy.stats.norm`, `scipy.stats.chi2`
- 自動微分ライブラリによる score 計算

ここでは直接呼ばず、[[スコア検定]] が「帰無仮説の下の傾きの大きさ」を見る検定であることが追える形にした。
