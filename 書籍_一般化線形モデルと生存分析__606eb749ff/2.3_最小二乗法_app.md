## 今回の更新ポイント

- 「平易だが省略しない」タブの中へ、原典の式 $e=y-X\hat{\beta}$、$e'e=(y-X\hat{\beta})'(y-X\hat{\beta})$、$(X'X)\hat{\beta}=X'y$ を直接埋め込み、別タブ往復なしで読めるようにした。
- $e'e$ の展開から正規方程式へ至るまでを、1 操作 1 行で補った。
- 交差項をまとめる理由、微分して 0 と置く理由、$(X'X)^{-1}$ を左から掛ける理由を、日本語でその場補足する形へ増補した。
- 2.4 で使う $e=y-X(X'X)^{-1}X'y$ への橋渡しを明示し、「2.4 は 2.3 の最後の式を差し戻す章」であることを app 内に書き込んだ。
- ダッシュボード側でも、RSS 地形の代表格子表と、2.4 へ続く残差条件の検算表を分けて表示する構成へ整理した。

## データの素性

- 原典 2.3 に固定データ表はないため、app では固定設計の 1 変数回帰データを補助生成している。
- 目的は、最小二乗法の目的関数、正規方程式、そして 2.4 へ続く残差条件の入口を直感的に確認することであり、実データ再現ではない。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |

| $\hat{\beta}$ | OLS 推定量 | `beta_hat` |

## 主要関数の意味

### 1. OLS 推定量

- `ols_beta(design_matrix, y_values)` が $X'X$ と $X'y$ を作り、連立一次方程式として OLS 解を返す。
- app 本文では、ここへ至るまでを $e'e$ の展開から 1 操作ずつ説明している。

### 2. RSS 地形

- `beta_grid_rss_table(...)` で切片・傾きの格子に対する RSS を並べ、等高線の元データを作る。
- これにより「どこが谷の底か」を視覚で追える。
- app では、グラフだけでなく、その格子表の代表行も同時に見せている。

### 3. 2.4 への橋渡しになる残差条件

- `residual_property_table(...)` で $X'e$ と $e'\hat{y}$ を計算し、OLS の直交条件を検算している。
- これは 2.3 の主結論そのものではないが、2.4 で $M$ を導入する前提になるため app 内で明示した。

## 平易化タブで何を補ったか

### 1. 目的関数の主語

- 「何を最適化しているか」を先に固定し、$e$ ではなく $e'e$ を最小化していることを明記した。

### 2. 交差項の整理理由

- $y'X\beta$ と $\beta'X'y$ は 1×1 のスカラーで、転置しても同じ値だから 2 倍へまとめてよいことを明記した。

### 3. 微分して 0 と置く理由

- 最小点では傾きが 0 になるという高校数学レベルの復習をその場で差し込んだ。

### 4. 逆行列を左から掛ける理由

- $(X'X)^{-1}(X'X)=I$ を使って $\hat{\beta}$ を孤立させる 1 手を、別節で丁寧に分解した。

### 5. 2.4 との接続

- $\hat{\beta}=(X'X)^{-1}X'y$ を残差へ戻すと $e=y-X(X'X)^{-1}X'y$ となり、2.4 の $M=I-X(X'X)^{-1}X'$ に直結することを app 本文とメモの両方へ残した。

## なぜこの構成にしたか

- 2.3 は、式変形だけ読むと「なぜ交差項をまとめられるのか」「なぜ微分して 0 なのか」「なぜ 2.4 で急に $M$ が出るのか」で止まりやすい。
- そこで app では、まず原典の式をその場に置き、次に 1 操作ずつ変形理由を言語化し、最後にダッシュボードで RSS 地形と残差条件を見せる順へ組み替えた。

## ブラックボックス化される候補

- `statsmodels.OLS.fit()`
- `sklearn.linear_model.LinearRegression`
- `numpy.linalg.lstsq`

ここではそれらを直接呼ばず、最小二乗法の計算手順と、2.4 へ渡る式のつながりが読める形を優先した。
