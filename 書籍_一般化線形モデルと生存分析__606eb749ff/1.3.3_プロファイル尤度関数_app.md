## 何を app 化したか

- 2 変数の尤度 $L(\theta,\phi)$ を、主役パラメータ $\theta$ ごとの 1 本の曲線 $L[\theta,\hat{\phi}(\theta)]$ へ畳み直す考え方。
- 正規分布については、$\mu$ のプロファイル対数尤度と $\sigma^2$ のプロファイル対数尤度を再現。
- ガンマ分布については、$\beta$ を固定したときの $\hat{\alpha}(\beta)$ と、そこから得られるプロファイル対数尤度を再現。

## データの素性

- この app は原典の 50 個の乱数列を復元していない。
- 原典に明示されている要約統計量だけを使って、図 1.2, 1.3, 1.4 の曲線を再構成している。
- したがって DGP は「新しい乱数生成」ではなく、「紙面に載っている集計値からの再構成」である。

固定した要約統計量:

```python
N_SAMPLES = 50
NORMAL_MEAN = 5.0848
NORMAL_MLE_VARIANCE = 42.0557
NORMAL_UNBIASED_VARIANCE = 42.9140

GAMMA_MEAN = 5.8671
GAMMA_MLE_VARIANCE = 9.7958
GAMMA_UNBIASED_VARIANCE = 9.9958
GAMMA_MLE_ALPHA = 3.514
GAMMA_MLE_BETA = 1.6696
```

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $\theta$ | 主役パラメータ | `mu`, `variance`, `beta` |
| $\phi$ | 補助パラメータ | `variance`, `mu`, `alpha` |
| $\hat{\phi}(\theta)$ | $\theta$ 固定時の補助パラメータ MLE | `normal_profile_variance`, `solve_alpha_given_beta` |
| $\bar{x}$ | 標本平均 | `NORMAL_MEAN`, `GAMMA_MEAN` |
| $\hat{\sigma}^2$ | 正規分布の分散 MLE | `NORMAL_MLE_VARIANCE` |
| $s^2$ | 不偏分散 | `NORMAL_UNBIASED_VARIANCE` |
| $\hat{\alpha},\hat{\beta}$ | ガンマ分布の MLE | `GAMMA_MLE_ALPHA`, `GAMMA_MLE_BETA` |

## 主要関数の意味

### 1. 正規分布の $\mu$ プロファイル

```python
def normal_profile_variance(mu):
    return NORMAL_MLE_VARIANCE + (mu - NORMAL_MEAN) ** 2

def normal_mu_profile_loglikelihood(mu):
    variance = normal_profile_variance(mu)
    return -(N_SAMPLES / 2.0) * (math.log(2.0 * math.pi) + 1.0) - (N_SAMPLES / 2.0) * math.log(variance)
```

- $\hat{\sigma}^2(\mu)=\hat{\sigma}^2+(\mu-\bar{x})^2$ を使い、生データなしで式 (1.14) を再構成している。
- 式 (1.16) も別関数で並列に計算し、「プロファイル」と「固定 MLE」の違いを可視化している。

### 2. 正規分布の $\sigma^2$ プロファイル

```python
def normal_sigma2_profile_loglikelihood(variance):
    return -(N_SAMPLES / 2.0) * (math.log(2.0 * math.pi) + math.log(variance)) - (N_SAMPLES * NORMAL_MLE_VARIANCE) / (2.0 * variance)
```

- $\hat{\mu}(\sigma^2)=\bar{x}$ を使って式 (1.18) をそのまま評価する。
- app では MLE 分散と [[不偏推定量]] の不偏分散も同時にマーカー表示している。

### 3. ガンマ分布の $\beta$ プロファイル

```python
def solve_alpha_given_beta(beta, tolerance=1e-10, max_iter=80):
    target = gamma_mean_log_x() - math.log(beta)
    ...

def gamma_beta_profile_loglikelihood(beta):
    alpha = solve_alpha_given_beta(beta)
    ...
    return loglik, alpha
```

- 原典の方程式

$$
\frac{\Gamma'(\alpha)}{\Gamma(\alpha)}
=
\frac{1}{n}\sum_{i=1}^n \log x_i - \log \beta
$$

  を、$\beta$ ごとに数値的に解いて $\hat{\alpha}(\beta)$ を得る。
- 生データが無いので、$\frac{1}{n}\sum \log x_i$ は $\hat{\alpha},\hat{\beta}$ から逆算している。

## なぜこの構成にしたか

- 1.3.2 が「MLE を求める章」なら、1.3.3 は「2 変数の尤度を 1 本の曲線へ畳み直す章」だから。
- したがって、ダッシュボードでは「何を固定し、何を裏で最適化し、どの曲線が図 1.2 / 1.3 / 1.4 に対応するか」を最優先で見せている。
- raw sample を持っていないことを隠さず、要約統計量からの再構成であると明記した。
