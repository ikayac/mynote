## 何を app 化したか

- 原典の中心式 (2.37)〜(2.47) を app 本体へ直接埋め込んだ。
- 正規誤差の線形回帰では、対数尤度を beta と sigma^2 で微分して `beta_tilde=(X'X)^(-1)X'y`, `sigma_tilde^2=e'e/n` を得る流れを、平易タブで途中式つきで追えるようにした。
- ダッシュボードでは、同一標本について beta の logL 等高線を描き、尤度最大点が OLS と一致することを視覚的に確認できるようにした。
- `sigma_tilde^2` と `s^2` を反復標本で比較し、(2.42) の下方バイアスと、(2.43) の分散を数値で確認できるようにした。
- フィッシャー情報行列 `I(theta)` とその逆 `I(theta)^(-1)` を現在標本から計算し、クラメールーラオ下限との対応を表で見せる構成にした。
- 後半では誤差をロジスティック分布へ変え、logL を 3 次元グリッド探索で評価し、解析的閉形式が消えて非線形 ML になることを体感できるようにした。

## データの素性

- 正規誤差の部分は固定デザインの単回帰標本を補助生成している。
- ロジスティック誤差の部分も同様に補助生成であり、目的は実データ再現ではなく、誤差分布を変えた瞬間に尤度地形と推定値がどう変わるかを見ることにある。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| beta_tilde | beta の MLE | `state['beta_hat']` |
| sigma_tilde^2 | sigma^2 の MLE | `state['sigma2_tilde']` |
| s^2 | sigma^2 の不偏推定量 | `state['s2']` |
| I(theta) | フィッシャー情報行列 | `fisher_information_table(...)` |
| I(theta)^(-1) | クラメールーラオ下限 | `inverse_frame` |
| logL | 尤度の対数 | `normal_log_likelihood(...)`, `logistic_log_likelihood(...)` |

## 平易タブで何を補ったか

### 1. OLS と MLE が一致する範囲

- 正規誤差・等分散・無相関という仮定のもとでだけ、beta に関する尤度最大化と RSS 最小化が同じ問題になることを明記した。

### 2. sigma_tilde^2 と s^2 の目的の違い

- `sigma_tilde^2` は尤度最大化の結果、`s^2` は不偏性を満たす推定量であり、同じ量を別基準で推定していると整理した。

### 3. 一致性と漸近的有効性

- 有限標本で biased でも、大標本で偏りと分散が消えるため一致性があること、情報行列から漸近的有効性が読めることを補った。

### 4. 非線形 ML の意味

- ロジスティック誤差では score 方程式が alpha, beta, phi の非線形連立式になり、正規回帰のような解析解が得られないことを数値探索で示した。

## 主要関数の意味

### 1. 正規誤差標本の生成と閉形式 MLE

- `normal_mle_state(...)` で OLS, RSS, sigma_tilde^2, s^2 を一括で計算する。

### 2. 情報行列

- `fisher_information_table(...)` で原典 (2.44), (2.45) に対応する行列を作る。

### 3. ロジスティック誤差の数値最尤法

- `logistic_log_likelihood(...)` で (2.47) に対応する logL を計算する。
- `logistic_grid_search(...)` で alpha, beta, phi の 3 次元グリッド探索を行い、非線形 ML の最大点を探す。

## なぜこの構成にしたか

- 2.9 は前半の正規線形回帰だけ見ると「MLE も OLS と同じ」で終わってしまいがちだが、本当の要点はその一致がどの仮定の上に立っているか、そして仮定を外すとどう崩れるかにある。
- そこで app では、前半で OLS と MLE の一致・不一致を定量化し、後半でロジスティック誤差の非線形 ML を置いて対比させた。

## ブラックボックス化される候補

- `statsmodels.OLS`
- `scipy.optimize.minimize`
- 一般的な MLE パッケージの optimizer

ここではそれらへ全面依存せず、対数尤度の地形と一階条件の意味が読める形を優先した。
