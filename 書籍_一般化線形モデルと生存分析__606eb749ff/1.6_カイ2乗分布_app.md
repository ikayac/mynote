## 何を app 化したか

- 原典の小区分 `(i)` から `(v)` を、そのまま app 内の内部タブとして分割した。
- `(i)` では $Z\sim N(0,1)$ から $Z^2\sim\chi^2(1)$ が出ることと、既出の $\bar{X}$、$\hat{p}$、$\hat{\sigma}^2$ の標準化平方が同じ型になることを確認できるようにした。
- `(ii)` では
  $f(v)=\dfrac{v^{m/2-1}\exp(-v/2)}{2^{m/2}\Gamma(m/2)}$
  を直接描き、$E(V)=m$、$\operatorname{var}(V)=2m$、さらに
  $\dfrac{(n-1)s^2}{\sigma^2}\sim\chi^2(n-1)$
  を標本分散の計算表とあわせて見せる構成にした。
- `(iii)` では、独立な標準正規の二乗和
  $\sum_{i=1}^{m} Z_i^2$
  が $\chi^2(m)$ に従う再生性を、1 組の観測表と分布ヒストグラムで示した。
- `(iv)` では、正規ベクトルの 2 次形式
  $(x-\mu)'\Sigma^{-1}(x-\mu)$
  と、中心化行列を使う場合の自由度の減少を、並列ヒストグラムで確認できるようにした。
- `(v)` では、
  $(\hat{\theta}-\theta)'I(\theta)(\hat{\theta}-\theta)$
  と
  $S(\theta)'I(\theta)^{-1}S(\theta)$
  を正規分布の $(\mu,\sigma^2)$ の例で実装し、後続の大標本検定にどうつながるかを見える形にした。

## データの素性

- 1.6 は理論中心の節であり、原典に固定の観測データ表はない。
- そこで app では、標準正規標本、正規母集団標本、Bernoulli 標本を補助生成し、カイ2乗分布へつながる計算を手で追えるようにした。
- したがってここでの DGP は「原典データの再掲」ではなく、「原典の数式を理解するための補助実験」である。

## 主要関数の意味

### 1. カイ2乗分布の pdf

```python
def chi_square_pdf(x_values, degrees_of_freedom):
    coefficient = 1.0 / ((2.0 ** (m / 2.0)) * math.gamma(m / 2.0))
    ...
```

- 原典の式 (1.43) をそのまま実装している。
- 既製の分布オブジェクトに隠さず、Gamma 関数を含む形を露出した。

### 2. 標本分散の計算

```python
centered = samples - sample_means[:, None]
s2_values = np.sum(centered ** 2, axis=1) / (n_samples - 1)
chi_square_values = ((n_samples - 1) * s2_values) / true_variance
```

- 原典の (1.44) と (1.46) に対応する。
- 不偏分散と、そのスケーリング後のカイ2乗統計量を同時に作っている。

### 3. 再生性の確認

```python
z_matrix = rng.normal(0.0, 1.0, size=(n_simulations, m_terms))
chi_square_sums = np.sum(z_matrix ** 2, axis=1)
```

- 独立標準正規の平方和を直接作り、$\chi^2(m)$ のヒストグラムと比較している。

### 4. 正規変数の 2 次形式

```python
q_true = np.sum((centered_true ** 2) / true_variance, axis=1)
q_centered = np.sum((mean_centered ** 2) / true_variance, axis=1)
```

- 平均既知の場合と、平均を標本平均で置いた場合の違いを並べるための実装。
- 自由度が $n$ から $n-1$ に減る様子を視覚的に比べられる。

### 5. MLE と score の 2 次形式

```python
q_theta = np.einsum("...i,ij,...j->...", delta, information_matrix, delta)
q_score = np.einsum("...i,ij,...j->...", score_matrix, inverse_information, score_matrix)
```

- 原典の (1.49), (1.50) に対応する。
- 正規分布の $(\mu,\sigma^2)$ という具体例を使い、有限標本の分布が漸近的に $\chi^2(2)$ に近づく様子を見る。 

## なぜこの構成にしたか

- 1.6 は数式の圧縮率が高く、本文だけだと「どの二乗和が、どの自由度のカイ2乗分布なのか」を見失いやすいから。
- そこで原典の `(i)` から `(v)` を、そのまま 5 つの内部タブへ分け、各小節ごとに観測内訳表と分布表示をセットにした。
- とくに最後の MLE と score の 2 次形式は、後で尤度比検定や Wald 検定を理解する土台になるので、単なる式紹介で終わらないようにした。
