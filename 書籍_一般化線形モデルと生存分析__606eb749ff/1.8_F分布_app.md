## 何を app 化したか

- 原典の `(i)` から `(iii)` を app 内の内部タブへ分けた。
- `(i)` では
  $X=(U/m_1)/(V/m_2)$
  をそのまま乱数で構成し、2 つの [[カイ2乗分布]] の比として F 分布が出ることを見せた。
- `(ii)` では F 分布の pdf を直接描き、自由度の組で右裾の長さ、平均、分散の存在条件がどう変わるかを確認できるようにした。
- `(iii)` では正規母集団からの 2 群標本分散を使い、
  $(s_1^2/\sigma_1^2)/(s_2^2/\sigma_2^2)$
  が $F(n_1-1,n_2-1)$ に従うことを、観測内訳表とヒストグラムで示した。

## データの素性

- 1.8 は理論中心の節であり、原典に固定の観測データ表はない。
- そこで app では、カイ2乗乱数と正規母集団からの標本を補助生成し、F 分布と分散比のつながりを手で追えるようにした。
- DGP は「原典データの再掲」ではなく、「原典の数式を理解するための補助実験」である。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $X\sim F(m_1,m_2)$ | 自由度 $(m_1,m_2)$ の F 分布 | `f_pdf(x_grid, m1, m2)` |
| $U$ | 分子側のカイ2乗成分 | `u_values` |
| $V$ | 分母側のカイ2乗成分 | `v_values` |
| $(U/m_1)/(V/m_2)$ | 定義に基づく F 統計量 | `f_values` |
| $s_1^2/s_2^2$ | 標本分散比 | `ratio_raw` |

## 主要関数の意味

### 1. F 分布の構成

```python
def simulate_f_definition(numerator_df, denominator_df, n_simulations, seed):
    u_values = rng.chisquare(numerator_df, size=n_simulations)
    v_values = rng.chisquare(denominator_df, size=n_simulations)
    f_values = (u_values / numerator_df) / (v_values / denominator_df)
```

- 原典の `(i)` の定義をそのままコード化している。
- F 分布乱数を直接呼ばず、U と V の部品を見せてから比を作る構成にした。

### 2. F 分布の pdf

```python
f_pdf(x_values, numerator_df, denominator_df)
```

- 原典の式 (1.53) を Gamma 関数つきで直接実装している。
- 分子自由度と分母自由度を動かして分布形の違いを見えるようにしている。

### 3. 標本分散比

```python
ratio_scaled = (s1_sq / sigma1_sq) / (s2_sq / sigma2_sq)
ratio_raw = s1_sq / s2_sq
```

- 原典の式 (1.54), (1.55) に対応する。
- 調整後の比と未調整の比を並べ、等分散仮定の有無で何が違うかを見やすくした。

## なぜこの構成にしたか

- 1.8 は F 分布の式だけでなく、「分散比を評価する基準線」として読むのが本質だから。
- そこで app では、まず定義を見せ、その後に分布形、最後に正規母集団の標本分散比へ落とす 3 段構成にした。
