## 💻 最小二乗推定量の手動計算（解析解）

残差平方和 $S = \sum(y_i - \hat{y}_i)^2$ を最小化するような切片 $\beta_0$ と傾き $\beta_1$ は、偏微分を行って 0 と置くことで、一発で求まる公式（解析解）が存在します。

公式は以下の通りです。
$$
\begin{align}
\hat{\beta_1} &= \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2} = \frac{\text{XとYの共分散}}{\text{Xの分散}} \\
\hat{\beta_0} &= \bar{y} - \hat{\beta_1} \bar{x}
\end{align}
$$

### NumPyへの翻訳

上記の$\sum$（シグマ）を使った計算は、Pythonの `for文` で回すと非常に遅くなりますが、**NumPy**の配列演算を活用すれば、まるで数式をそのまま書くかのように実装できます。

```python
import numpy as np

# X, y はそれぞれデータが格納された1次元のNumPy配列とする

# 1. 傾き (β1) の計算: = Cov(X,Y) / Var(X)
# np.sum() はシグマ記号と全く同じ役割を果たします。
numerator = np.sum((X - np.mean(X)) * (y - np.mean(y))) # 分子：共分散に相当
denominator = np.sum((X - np.mean(X))**2)               # 分母：分散に相当
b1_hat = numerator / denominator

# 2. 切片 (β0) の計算: = E[Y] - β1 * E[X]
b0_hat = np.mean(y) - b1_hat * np.mean(X)
```

> [!info] スクラッチ実装の意味
> `scikit-learn` の `LinearRegression().fit(X, y)` を使うとたった1行で終わりますが、その裏側ではまさにこの「共分散 / 分散」の行列演算が行われています。
> 式の形からわかる通り、**「$X$のばらつき（分母）」に対して「$X$と$Y$の連動したばらつき（分子）」がどれくらい大きいか** が、つまり「直線の傾き」そのものになる、という美しい関係が現れています。

## 🎲 ダミーデータの生成と i.i.d.

アプリの中で体験してもらったデータは、**「[[i.i.d.]]」**(独立同一分布) および等分散性の仮定を完璧に満たすように、以下のロジックで生成しています。

```python
# 真のパラメータ
true_b0, true_b1 = 2.0, 3.5

# Xの生成
X = 10 * np.random.rand(n_samples)

# ランダムなノイズ（誤差）の生成 ← これが重要！
# 全ての点において、同じ「標準偏差3.0」の正規分布から独立して引っ張ってきている。
epsilon = np.random.randn(n_samples) * 3.0

# Yの生成 (真の直線 + ランダムなノイズ)
y = true_b0 + true_b1 * X + epsilon
```

> [!important] もしここで等分散性が崩れたら？
> もし `epsilon = np.random.randn(n_samples) * X` のように「Xが大きいほどノイズのブレも大きくなる」書き方をしてしまうと、最小二乗法の仮定である等分散性が崩れます。その場合は**重み付き最小二乗法**など、別のアプローチが必要になります。
