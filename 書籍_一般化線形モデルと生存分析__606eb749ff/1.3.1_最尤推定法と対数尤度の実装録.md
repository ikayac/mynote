## 1. 原典で何をしているか

1.3.1 節は、観測値 $(x_1, \ldots, x_n)$ を固定し、パラメータ $\theta$ を変数として扱うときの関数

$$
L(\theta ; x_1, x_2, \ldots, x_n)
$$

を **[[尤度関数]]** と呼ぶ、という定義から始まります。

その具体例として本書は、**10回ベルヌーイ試行をして6回成功した**という観測結果を使っています。ここで興味があるのは「成功確率 $p$ がどの値なら、この結果はもっともらしいか」です。

二項分布の尤度関数は

$$
L(p)=\binom{n}{x}p^x(1-p)^{n-x}
$$

であり、本の例 $n=10, x=6$ では

$$
L(p)=\binom{10}{6}p^6(1-p)^4
$$

です。

---

## 2. アプリで使ったスクラッチ実装

今回のアプリでは、原典の式をそのまま Python に落としました。ブラックボックスな統計ライブラリは使っていません。

```python
import math

def likelihood_binomial(n_trials, successes, p):
  if p < 0.0 or p > 1.0:
    return 0.0
  if p == 0.0:
    return 1.0 if successes == 0 else 0.0
  if p == 1.0:
    return 1.0 if successes == n_trials else 0.0
  return math.comb(n_trials, successes) * (p ** successes) * ((1.0 - p) ** (n_trials - successes))

def log_likelihood_binomial(n_trials, successes, p):
  if p <= 0.0 or p >= 1.0:
    return float("-inf")
  return (
    math.log(math.comb(n_trials, successes))
    + successes * math.log(p)
    + (n_trials - successes) * math.log(1.0 - p)
  )
```

ポイントは次の3つです。

1. `math.comb(n_trials, successes)` が $\binom{n}{x}$ に対応します。
2. `p ** successes` が $p^x$ に対応します。
3. `(1.0 - p) ** (n_trials - successes)` が $(1-p)^{n-x}$ に対応します。

## 3. 尤度では何を固定し、何を動かしているか

原典の初学者がつまずきやすい点は、**確率の計算と尤度の計算では、固定するものが逆**だということです。

- 確率: $p$ を固定し、どんな結果が出るかを見る。
- 尤度: 観測結果 $(x_1, \ldots, x_n)$ を固定し、$p$ を動かしてどれがもっともらしいかを見る。

アプリでは、観測列そのものも `sample` として表示しています。

```python
import numpy as np

def bernoulli_sample(n_trials, successes):
  sample = np.zeros(n_trials, dtype=int)
  sample[:successes] = 1
  return sample
```

ただし、この 0 と 1 の並び順は本質ではありません。本節で効いているのは **成功回数 $x$ と試行回数 $n$** です。

---

## 4. 尤度は確率分布ではない

本書が強調している重要点は、尤度 $L(p)$ は $p$ の確率分布ではない、ということです。実際、

$$
\int_0^1 L(p) \, dp = \int_0^1 \binom{n}{x} p^x (1-p)^{n-x} \, dp = \frac{1}{n+1}
$$

となり、1 にはなりません。

したがって意味があるのは $L(p)$ の絶対値そのものではなく、**同じ観測結果に対する尤度の比較**です。そこで本では尤度比

$$
\frac{L(0.6)}{L(0.1)} = \frac{0.25082}{0.00013778} = 1820.4
$$

を計算し、$p=0.6$ の世界の方が $p=0.1$ の世界よりはるかにもっともらしいことを示しています。

---

## 5. 対数尤度を併記した理由

本の最後では、対数変換が単調増加変換なので、$L(p)$ を最大にする $p$ と $\log L(p)$ を最大にする $p$ は一致すると述べています。アプリでもこれを目で確認できるようにしました。

$$
\log L(p)=\log \binom{n}{x} + x\log p + (n-x)\log(1-p)
$$

今回は $p$ が1個だけなので、計算量のために対数化しているわけではありません。しかし今後パラメータや標本数が増えると、対数尤度で扱うことがほぼ必須になります。

### 5.1 なぜ $L(p)$ と $\log L(p)$ は山型になるのか

アプリでは、曲線の見た目だけで終わらせず、

$$
\log L(p)=\log \binom{n}{x}+x\log p+(n-x)\log(1-p)
$$

を項ごとに分解して表示しています。これによって、山の形の原因が式のどこにあるかを追えます。

1. $\log \binom{n}{x}$ は **定数項** です。$p$ に依存しないので、グラフを上下へ平行移動するだけで、頂上の位置には影響しません。
2. $x \log p$ は **成功側の寄与** です。$p \to 0$ で $\log p \to -\infty$ なので、左端を強く押し下げます。成功回数 $x$ が大きいほど、この効果は強くなります。
3. $(n-x) \log(1-p)$ は **失敗側の寄与** です。$p \to 1$ で $\log(1-p) \to -\infty$ なので、右端を強く押し下げます。失敗回数 $n-x$ が大きいほど、この効果は強くなります。

したがって、左を押し下げる項と右を押し下げる項の綱引きで、中央のどこかに 1 個だけ頂上ができます。

### 5.2 頂上が $\hat{p}=\dfrac{x}{n}$ になる理由

アプリでは一階微分も別図で表示しています。

$$
\frac{d\log L(p)}{dp}=\frac{x}{p}-\frac{n-x}{1-p}
$$

この式は、

- $\dfrac{x}{p}$: 成功側の項が「もっと $p$ を大きくしたい」と押す力
- $\dfrac{n-x}{1-p}$: 失敗側の項が「$p$ を大きくしすぎるな」と押し返す力

の差です。この差が 0 になる場所が頂上であり、解くと

$$
\hat{p}=\frac{x}{n}
$$

になります。

### 5.3 なぜ山が 1 個しかないのか

さらに二階微分は

$$
\frac{d^2\log L(p)}{dp^2}=-\frac{x}{p^2}-\frac{n-x}{(1-p)^2}
$$

で、$0 < p < 1$ なら常に負です。つまり $\log L(p)$ は全域で山型で、複数の山や平坦な台地はできません。$L(p)$ はその指数関数なので、最大点の位置は同じです。

## 7. データの素性と生成プロセス（DGP）

今回のアプリで使っているデータは、**原典の例そのものを再現した人工的な観測列**です。ランダムに新しい標本を引いているわけではなく、観測結果 $n=10, x=6$ を起点に理解させるため、固定の 0/1 列を組み立てています。

```python
def bernoulli_sample(n_trials, successes):
  sample = np.zeros(n_trials, dtype=int)
  sample[:successes] = 1
  return sample
```

つまり DGP というよりは、**「原典が所与としている観測結果を、可視化のために配列として表現した」**という位置づけです。

## 7.1 アプリ本体のコード解説タブで何を説明しているか

今回の改修では、Obsidian ノートだけでなくアプリ本体にも**全使用コードの解説タブ**を追加した。そこで説明している内容は次の通りである。

1. `bernoulli_sample(...)`
  原典が要約形でしか与えていない観測結果を、表表示のために 0/1 配列へ再表現する補助関数。
2. `likelihood_binomial(...)`
  二項尤度

  $$
  L(p)=\binom{n}{x}p^x(1-p)^{n-x}
  $$

  をそのまま実装した中心関数。
3. `log_likelihood_binomial(...)`
  対数尤度を計算し、端点では $\log 0$ を避けるために $-\infty$ を返す関数。
4. `likelihood_curve(...)`, `log_likelihood_curve(...)`
  格子点上で尤度を反復評価し、Plotly に渡す曲線配列を作る関数。
5. `log_likelihood_components(...)`, `score_curve(...)`, `second_derivative_curve(...)`
  項分解図、一階微分図、二階微分図を作るための解析補助関数。
6. `make_book_table(...)`
  原典の表 1.1 に対応する離散表を、$p$ を刻みながら再現する関数。

これにより、学習者は Obsidian ノートへ移動しなくても、アプリ画面の中だけで「見えている図」と「その図を作るコード」の対応を確認できる。

## 8. 次節 1.3.2 への橋渡し

この節では「どこが山の頂上か」をグラフで眺めました。次節 1.3.2 では、この対数尤度を微分して

$$
\frac{d\log L(p)}{dp} = \frac{x}{p} - \frac{n-x}{1-p} = 0
$$

から

$$
\hat{p} = \frac{x}{n}
$$

を解析的に導きます。1.3.1 は絵で掴む段階、1.3.2 は式で確定させる段階です。
