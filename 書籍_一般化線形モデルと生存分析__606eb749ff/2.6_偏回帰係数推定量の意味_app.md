# 2.6 偏回帰係数推定量の意味 app

> [!abstract] 概要
> 原典 2.6 を、偏回帰係数が「他の説明変数の線形影響を除いた後の限界効果」であることを示す Streamlit app として構成した。

## 何を app 化したか

- 原典の核となる式 (2.24), (2.25), (2.26) を app 本体へ直接埋め込んだ。
- 平易タブで、X を X1 と X2 に分け、M1 を導入し、beta_hat_2=(X2'M1X2)^(-1)X2'M1y までを 1 操作ずつ分解した。
- ダッシュボードでは、2 説明変数回帰を補助生成し、フルモデルの beta_hat_2 と、M1X2 への回帰係数、M1Y を M1X2 に回帰した係数が一致することを数値で確認できるようにした。
- 単回帰の X2 係数も併置し、偏回帰係数と単回帰係数が一般には違うことを視覚的に見せる構成にした。

## データの素性

- 原典 2.6 に固定データ表はないため、app では 2 説明変数の回帰データを補助生成している。
- 目的は実データ再現ではなく、X1 と X2 を相関させたときに、偏回帰係数の意味が単回帰とどう違うかを確認することである。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| X1 | 他変数として除く説明変数群 | `x1_design` |
| X2 | 意味を読みたい説明変数 | `x2_values` |
| M1 | X1 側の残差生成行列 | `residual_maker_matrix(x1_design)` |
| M1X2 | X2 を X1 で回帰した残差 | `m1x2` |
| M1Y | Y を X1 で回帰した残差 | `m1y` |
| beta_hat_2 | 偏回帰係数推定量 | `ols_beta(full_design, y_values)[2]` |

## 平易タブで何を補ったか

### 1. M1X2 の意味

- M1X2 は X2 そのものではなく、X1 の線形関数で説明できる部分を除いた残りであることを明記した。

### 2. M1Y の意味

- Y 側からも X1 の線形影響を除けるので、beta_hat_2 は M1Y を M1X2 に回帰した係数としても読めることを補った。

### 3. 単回帰係数との差

- X1 と X2 が相関していれば、X2 の単回帰係数は X1 の影響まで抱え込むため、偏回帰係数と一般には一致しないことをダッシュボードと本文の両方で示した。

## 主要関数の意味

### 1. 2 説明変数データの生成

- `generate_two_predictor_sample(...)` で相関した X1, X2 と Y を補助生成する。

### 2. 残差化

- `residualize_against(...)` で M1X2 と M1Y を作る。

### 3. 係数一致の検算

- `simple_regression_slope(m1x2, m1y)` とフルモデルの `ols_beta(...)` を比較し、(2.25) の意味を数値で確認する。

## なぜこの構成にしたか

- 2.6 は図表のない線形代数中心の節なので、数式だけだと「何が起きているか」が掴みにくい。
- そこで app では、平易タブで分割行列の導出を 1 操作ずつ示し、その後にダッシュボードで残差化した散布図と係数一致を見せる順にした。

## ブラックボックス化される候補

- `statsmodels.OLS`
- `numpy.linalg.solve`
- 各種 partial regression plot 生成ルーチン

ここではそれらを直接は使わず、M1X2, M1Y, beta_hat_2 の対応が読める形を優先した。
