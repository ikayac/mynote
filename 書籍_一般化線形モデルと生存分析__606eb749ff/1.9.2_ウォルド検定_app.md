## 何を app 化したか

- 原典の式 (1.61) から (1.63) の考え方を、二項分布の成功確率 $p$ で実演した。
- 推定値 $\hat{p}$ と帰無仮説 $p_0$ のズレを、標準誤差で割った $Z$ と、その二乗の $W=Z^2$ を並べて見せた。
- 帰無仮説の下での反復標本から、
  $Z \overset{asy}{\sim} N(0,1)$
  と
  $W \overset{asy}{\sim} \chi^2(1)$
  を確認できるようにした。

## データの素性

- 原典に固定データ表はないため、app では二項分布の成功回数を補助生成している。
- 目的は実データ再現ではなく、推定量のズレが標準誤差でどう評価されるかを体感することにある。

## 原典の記号とコードの対応

| 原典の記号 | app の意味 | コード変数 |
|---|---|---|
| $\hat{\theta}$ | 推定量 | `mle_probability` |
| $\theta_0$ | 帰無仮説の母数 | `null_probability` |
| $Z$ | 標準化されたズレ | `wald_z` |
| $W$ | Wald 統計量 | `wald_value` |

## 主要関数の意味

### 1. Wald 統計量

```python
def wald_statistic(n_trials, successes, null_probability):
    z_value = wald_z_statistic(n_trials, successes, null_probability)
    return z_value ** 2
```

- 原典の「推定量のズレを標準化して二乗する」考えを、そのままスカラー版にしている。

### 2. 標準誤差

```python
def wald_standard_error(n_trials, successes):
    mle_probability = unrestricted_mle(n_trials, successes)
```

- 推定量側の情報量から標準誤差を出す構造になっている。
- LR や LM と違って、評価点が `p_hat` 側にあるのが Wald の特徴。

## なぜこの構成にしたか

- 1.9.2 は、「帰無仮説そのもの」より「推定値のズレ」を見る発想が肝だから。
- そこで app では、固定データに対する $W(p_0)$ 曲線と、帰無仮説の下での $Z, W$ の分布確認を分けた。

## ブラックボックス化される候補

- `statsmodels` の係数表の z 値 / Wald test
- `scipy.stats.norm`, `scipy.stats.chi2`
- GLM / 生存モデルの組み込み検定関数

ここではそれらを直接使わず、[[ウォルド検定]] の組み立てを手元で追える形を優先した。
